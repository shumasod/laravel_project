# 旅行検索サイト 要件定義書

## 1. プロジェクト概要

### 1.1 目的
大手旅行サイト（じゃらん、楽天トラベル、Booking.com、一休.com等）を参考にした、
宿泊施設検索・予約機能を持つ旅行検索プラットフォームの構築。

### 1.2 参考サイト
| サイト | 特徴 | 参考ポイント |
|--------|------|-------------|
| 楽天トラベル | 40,000件以上の施設、豊富なフィルター | 絞り込み検索、ポイント還元 |
| じゃらんnet | 温泉宿が豊富、ビジュアル重視 | 口コミ表示、目的別検索 |
| Booking.com | グローバル対応、豊富な写真 | 地図検索、無料キャンセル表示 |
| 一休.com | 高級志向、厳選施設 | 会員ランク、コンシェルジュ機能 |
| Expedia | AI活用、パッケージ予約 | 航空券+ホテル一括予約 |

## 2. 機能要件

| 項目 | 必須 | データ型 | 説明 |

### 2.4 予約フロー（Booking）

#### 2.4.1 予約ステップ
```
[STEP 1: プラン選択] → [STEP 2: 情報入力] → [STEP 3: 確認] → [STEP 4: 完了]
```

#### 2.4.2 STEP 1: プラン選択
- 部屋タイプ選択
- プラン選択（食事条件、特典等）
- オプション選択（レイトチェックアウト、アメニティ追加等）
- 料金明細表示

#### 2.4.3 STEP 2: 情報入力
**宿泊者情報**
| 項目 | 必須 | 備考 |
|------|------|------|
| 代表者氏名（漢字） | ○ | |
| 代表者氏名（フリガナ） | ○ | |
| メールアドレス | ○ | 予約確認メール送信先 |
| 電話番号 | ○ | 緊急連絡先 |
| 住所 | - | |
| 到着予定時刻 | ○ | 15:00〜24:00 選択 |
| 特別リクエスト | - | テキストエリア |

**同行者情報（オプション）**
| 項目 | 必須 |
|------|------|
| 氏名 | - |
| 年齢区分 | - |

**支払い方法**
| 方法 | 説明 |
|------|------|
| 現地払い | チェックイン時に支払い |
| 事前カード決済 | クレジットカード（即時決済） |
| 後払い | 宿泊後の請求書払い（法人向け） |

#### 2.4.4 STEP 3: 確認
- 予約内容確認
- 料金明細確認
- キャンセルポリシー確認
- 利用規約同意

#### 2.4.5 STEP 4: 完了
- 予約番号発行
- 確認メール送信
- 予約詳細表示
- カレンダー登録リンク
